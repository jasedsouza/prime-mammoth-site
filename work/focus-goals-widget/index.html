Getting started

Pin it.
Make it yours.

  1. Get Focus from Microsoft Store.
  2. Press Win + W to open Windows Widgets.
  3. Choose Add widgets, find Focus and pin it.
  4. Select Set your goals to begin.

Focus is a Windows Widgets Board widget, not a standalone desktop application. It has no separate app window or Start menu application. Once pinned, resize it to Medium or Large to edit your goals.
